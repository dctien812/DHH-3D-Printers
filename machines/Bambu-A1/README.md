# Bambu A1

Mã máy trong dự án: `A1`. Địa chỉ trong LAN ngày 2026-11-24: 192.0.2.122.

## Đã biết

- Firmware 01.09.00.00 (bản mới nhất theo trang của hãng)
- Chế độ cloud, đã gắn tài khoản
- Không có AMS
- Không buồng kín: không in ABS / ASA

Nguồn: gói quảng bá của máy trên LAN ngày 2026-11-24. Bên trong máy (lỗi treo, đầu phun, giờ in) chưa đọc được.

## Cần điền

Mục in đậm là cần trước ngày làm. **Không ghi mã truy cập, serial hay mật khẩu vào đây.**

| # | Mục | Trả lời |
|---|---|---|
| 1 | **Lỗi / HMS đang treo trên màn hình (ghi mã, hoặc "không có")** | |
| 2 | **Đầu phun đang lắp: cỡ, loại (thép không gỉ / thép tôi / high flow)** | |
| 3 | Tấm in đang dùng (PEI nhám / trơn / khác) | |
| 4 | Tổng giờ in (nếu máy hiển thị) | |
| 5 | Lần bảo trì gần nhất (tra dầu, tra mỡ, vệ sinh) | |
