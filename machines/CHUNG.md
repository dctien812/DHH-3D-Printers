# Câu hỏi chung (không riêng máy nào)

**Không ghi mã truy cập, serial hay mật khẩu vào đây.**

## Quyết định đang chờ

| # | Câu hỏi | Trả lời |
|---|---|---|
| **1** | "Bambu PETG" đang dùng là dòng nào: PETG HF, PETG Basic hay PETG Translucent? | |
| **2** | SAVE_CONFIG đang treo trên hai Voron (nhiều khả năng là bed mesh sau lần in): bỏ, hay lưu lại trước khi khởi động lại Klipper? | |
| 3 | Tên máy trong hồ sơ Orca mới: "DHH Trident 0.4", "DHH V2.4 0.4", "DHH H2S 0.4", "DHH P1S 0.4", "DHH A1 0.4", "DHH A1 Mini 0.4". Giữ hay đổi? | |
| 4 | Phiên bản OrcaSlicer đang dùng (Help → About). File cấu hình ghi 2.5.1 | |
| 5 | Cắt lịch thành 3 ngày (ngày 1: chuẩn bị, cân đai, bảo trì, in thử PLA; ngày 2: hai loại PETG; ngày 3: ABS, in bù, lắp chéo, nạp bo V2.4). Đồng ý hay muốn cắt khác? | |

## Nhựa và dụng cụ

| # | Mục | Trả lời |
|---|---|---|
| **6** | Cuộn trắng sẵn có: Bambu PLA, Bambu PETG, Tinmorry PETG-ECO, Tinmorry ABS Pro — số cuộn và còn khoảng bao nhiêu | |
| **7** | Dùng chung một cuộn cho nhiều máy, hay mỗi máy một cuộn | |
| **8** | Sấy nhựa bằng gì; nhiệt độ và thời gian thường dùng cho từng loại | |
| **9** | Thước cặp: loại, độ phân giải | |
| 10 | Cách đo căng đai (ứng dụng đo tần số trên điện thoại, đồng hồ đo đai) | |
